# RecurKit

Це навчальний проєкт: бібліотека на Python для календарних повторень за стандартом RFC 5545 (iCalendar). Вона розбирає правила RRULE, генерує дати повторень і враховує часові пояси. Ядро написане лише на стандартній бібліотеці Python.

## Технологічний стек

- **Мова:** Python 3.12
- **Залежності ядра:** лише стандартна бібліотека
- **Тестування:** pytest + Hypothesis
- **Лінтер:** ruff
- **Перевірка типів:** mypy (strict)

## Інструкції з налаштування

1. Клонуйте репозиторій:

   ```
   git clone https://github.com/Anasstassik/recurkit.git
   ```

2. Перейдіть в каталог проєкту:

   ```
   cd recurkit
   ```

3. Створіть і активуйте віртуальне оточення:

   ```
   python -m venv .venv
   .venv\Scripts\activate
   ```

4. Встановіть проєкт із залежностями для розробки:

   ```
   pip install -e ".[dev]"
   ```

5. Запустіть перевірки й тести:

   ```
   ruff check .
   mypy recurkit
   pytest -q
   ```
